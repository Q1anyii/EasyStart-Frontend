# 前端基础学习（秋招副线）

> 给"看得懂但写不出"的求职者设计的动手路线：**语法 → 对应 demo → 语法整合 demo → 小项目 → 复现项目**。
> 定位：秋招补全岗位拼图（AI 应用 / 全栈 / DevOps / 后端方向）的副线，放缓节奏，不挤占项目与算法复习。

## 为什么是这个路线

核心痛点：看了不少教程，代码看得懂，但自己**完全写不出来**——因为没实际敲过 JS。所以本项目的原则：

- **亲手敲**：每个 demo 都要新建副本逐字敲一遍，禁止复制粘贴
- **改动任务**：每个 demo 底部有 2~4 个改动任务，这是"看得懂 → 写得出"的关键一步
- **打卡复盘**：每课完成在 `demo/LEARNLOG.md` 打卡（日期 / 知识点 / 卡点 / 用时 / 改动题）
- **自述总结**：学完用自己的话完整复述一遍，卡壳就看文档，能说出来才算过

## 每课学习流程（固定模板）

1. 浏览器打开 demo 文件（双击即可），边看渲染效果边读代码注释
2. 新建自己的副本（如 `my-xxx.html`），**亲手逐字敲一遍，禁止复制粘贴**
3. 完成文件底部的「改动任务」——这是"看得懂 → 写得出"的关键一步
4. 完成后在 `demo/LEARNLOG.md` 打卡（日期 / 知识点 / 卡点 / 用时 / 改动题）
5. 自述总结：用自己的话把本课知识点完整复述一遍，卡壳就看注释/文档

## Git 规则

- **先提交，不推送**（除非用户明确要求推送）
- 一课/一阶段一个完成节点 = 一次提交；提交前先审查改动任务是否完成、打卡是否补齐
- 只提交与本次学习相关的文件，不 sweep 无关改动
