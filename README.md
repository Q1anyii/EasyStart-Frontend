# 前端练习路线

> 动手路线：**语法 → 对应 demo → 语法整合 demo → 小项目 → 复现项目**。

## 路线原则

把每个语法点落到能亲手写出来的代码上，原则：

- **亲手敲**：每个 demo 都新建副本逐字敲一遍，不复制粘贴
- **改动任务**：每个 demo 底部有 2~4 个改动任务，是从理解到动手的关键一步
- **复盘记录**：每课完成在 `demo/LEARNLOG.md` 记录（日期 / 知识点 / 卡点 / 用时 / 改动题）
- **自述总结**：学完用自己的话完整复述一遍，卡壳就看文档，能说出来才算过

## 每课流程（固定模板）

1. 浏览器打开 demo 文件（双击即可），边看渲染效果边读代码注释
2. 新建自己的副本（如 `my-xxx.html`），**亲手逐字敲一遍，禁止复制粘贴**
3. 完成文件底部的「改动任务」
4. 完成后在 `demo/LEARNLOG.md` 记录（日期 / 知识点 / 卡点 / 用时 / 改动题）
5. 自述总结：用自己的话把本课知识点完整复述一遍，卡壳就看注释/文档

## Git 规则

- 一课/一阶段完成节点 = 一次提交
- 提交前先审查改动任务是否完成、记录是否补齐
- 只提交与本次相关的文件，不 sweep 无关改动
