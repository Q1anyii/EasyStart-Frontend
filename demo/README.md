# demo 学习目录（前端基础路线 v2）

> 路线：**语法 → 对应 demo → 语法整合 demo → 小项目 → 复现项目**
> 规则：每个 demo 亲手敲、禁止复制粘贴；做完文件底部「改动任务」才算过关；完成后在 `LEARNLOG.md` 打卡。
> 说明：旧版路线文档 `../前端学习路线.md`（TS→Vue3→chat-stream-lite）保留为「阶段四复现目标 + 面试话术」的参考，本目录专注基础动手练习。

## 目录结构

| 文件夹 | 阶段 | 内容 |
| --- | --- | --- |
| `00-htmlcss-refresh` | 阶段0（可选） | HTML/CSS 快速回顾：H5 语义标签、盒模型、Flex、CSS3 圆角/伪类 |
| `01-syntax` | 阶段一 | JS 语法 + 单点 demo（每个语法点一个文件） |
| `02-integrated` | 阶段二 | 语法整合 demo：TodoList / 随机点名器 / 图片轮播 / 简易计算器 |
| `03-projects` | 阶段三 | 小项目：记账本 / 天气查询 / 文章列表 |
| `04-reproduce` | 阶段四 | 复现项目（候选目标：chat-stream-lite，TS + Vue3 对话流式渲染） |

## 每课流程

1. 打开 demo 文件，先读代码注释（讲解内嵌）
2. 新建自己的副本，**亲手逐字敲一遍**（禁止复制粘贴）
3. 完成文件底部的「改动任务」（2~4 个）
4. 在 `LEARNLOG.md` 打卡：知识点 / 卡点 / 用时
5. 自述总结：用自己的话完整复述一遍本节知识点，卡壳就回去看文档
