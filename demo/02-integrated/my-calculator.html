讲解都写在下方 <script> 的注释里：先读注释，再新建副本亲手敲一遍（my-calculator.html），最后做「改动任务」。注意：现在 "." 和 "⌫" 两个键没功能——对应任务 2/3。

改动任务（做完才过关）

  1. 除零保护：点 "÷" 再点 "0" 再点 "="，现在会显示 Infinity——改成显示"不能除以0"；注释写一句：为什么 Infinity 对用户没有意义
  2. 小数点：给 "." 键接逻辑（追加进 current），但一个数里不能有两个小数点（用 current.includes(".") 守卫）；注释写一句：为什么小数用字符串拼而不是直接数字相加
  3. 退格键 ⌫：删掉 current 最后一位（current.slice(0, -1)）；注释写一句：为什么用切片字符串而不是数字除法
  4. 键盘支持：在 document 上监听 keydown，让键盘也能算——映射表：数字 0-9 → 数字键；+ - / * → 对应运算符（注意键盘 ÷ 是 "/"、× 是 "*"）；回车 → 等号；c → 清空
