    改动任务（做完才过关）

    1. 删除功能：每个 li 加一个"删除"按钮，点击后把对应 todo 从数组删掉（splice 或 filter 二选一），再 render()；注释写一句你为什么选这个方法
    2. 回车添加：在输入框按 Enter（keydown + e.key === "Enter"）也能添加，不许点按钮
    3. 统计升级：在 #stats 里再加一项"未完成 X 条"（用 filter 把 done 为 false 的筛出来）
    4. 清空已完成：加一个"清除已完成"按钮，把 done 为 true 的待办全删掉（提示：重新赋值 todos = todos.filter(...) 但要用 let 声明数组）
