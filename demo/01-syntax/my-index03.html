改动任务（做完才过关）

  1. 用函数声明写一个 greet(name)，返回问候语字符串；再把它改写成箭头函数，两种写法都调用打印
  2. 用单行箭头函数（省略花括号和 return 的那种）写 adult(age)，返回 age >= 18 的判断结果，分别试 17 和 18
  3. 实验块级作用域：在 if (true) { ... } 里分别用 let 和 var 声明一个变量，块外打印它们——观察 let 报错（块级作用域）、var 能访问（var 没有块级作用域）
  4. 默认参数：写 function fn(a, b = 10)，只传一个参数调用，打印结果，观察 b 用了默认值
