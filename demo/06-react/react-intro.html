React 第1课：JSX 与组件

阶段六开课。React 的核心思想：组件化——把页面拆成一个一个小零件，每个零件是一个"返回 HTML 的函数"。今天学 JSX 和 props。

改动任务（做完才过关）

  1. 新建一个组件：写一个 Footer 函数组件，返回一个 <p> 显示"© 2026 前端学习"，加进 App 里（注释写：为什么组件名要大写开头，小写会怎样）
  2. props 传参：给 Welcome 组件加一个 city prop（如 city="南昌"），欢迎语改成"你好，南昌！"（注释写：props 和 JS 函数参数有什么相似处）
  3. 列表渲染：把 skills 数组用 skills.map(...) 渲染成一组 <li>，放进一个 <ul>（注释写：为什么 React 要求 map 出来的每个元素有唯一的 key）
  4. 三元条件渲染：给 TodoItem 加一个 done prop，done 为 true 时文字加删除线 text-decoration: line-through（注释写：三元表达式和 if/else 在 JSX 里的区别）
