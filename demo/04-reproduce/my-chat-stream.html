阶段四复现项目：一个最简聊天界面。今天做：发消息 → 渲染气泡 → 模拟 AI 回复。明天做：localStorage 存历史 + 自动滚动 + "正在输入"状态。

上半改动任务（做完才过关）

  1. 按 Enter 发送：input 上监听 keydown，key === "Enter" 时触发和按钮一样的发送（注释写：为什么把发送逻辑抽成 send() 函数而不是复制一遍）
  2. AI 回复改成随机：现在 AI 永远回同一句，改成从几句预设回复里随机挑一句（数组 + Math.random() + Math.floor()，衔接点名器）
  3. 空消息守卫：输入框空或全空格时点发送不做任何事（trim() 判断）
  4. 发送后清空并聚焦：发送后 input.value = "" 并 input.focus()，方便连续输入（注释写：为什么 focus 是体验细节不是功能）

下半改动任务（在你自己的 my-chat-stream.html 上加）

  1. localStorage 持久化：messages 改动后 save() 存 localStorage（JSON.stringify），页面加载时 load() 读出来（衔接记账本的 load/save 循环）
  2. 自动滚动到底部：每次 render 后 messagesBox.scrollTop = messagesBox.scrollHeight（注释写：为什么新消息要滚到底而不是停在上面）
  3. "正在输入"状态：AI 回复延迟期间，先在列表里插一个 { role: "ai", text: "正在输入..." } 的气泡，AI 真正回复来了后把这个占位气泡替换掉（注释写：为什么要先显示"正在输入"而不是干等 800ms）
  4. 清空对话按钮：头部加一个"清空对话"按钮，点击后 messages 清空 + localStorage.removeItem + render（注释写：为什么清空也要走 save/render 循环）
