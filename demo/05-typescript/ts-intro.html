TypeScript 速成

TS = JS + 类型标注。你有 Java 基础，核心概念就是"把 Java 的类型系统搬过来"。左边是 TS 代码，右边是运行结果。

▼ TypeScript 代码（改这里，下面实时运行）
// ========== 1. 基本类型标注 ==========
let name: string = "张三";
let age: number = 20;
let isStudent: boolean = true;

// ========== 2. 接口（interface）：定义对象结构 ==========
interface User {
  name: string;
  age: number;
  email?: string;  // ? = 可选字段
}

const u: User = { name: "李四", age: 22 };

// ========== 3. 函数类型：参数 + 返回值 ==========
function greet(user: User): string {
  return `你好，${user.name}，今年${user.age}岁`;
}

// ========== 4. 联合类型：可以是多种类型之一 ==========
function printId(id: number | string): void {
  console.log("ID: " + id);
}

// ========== 5. 数组类型 ==========
const scores: number[] = [90, 85, 95];
const names: Array<string> = ["a", "b"];

// ========== 运行输出 ==========
console.log("name:", name);
console.log("greet:", greet(u));
printId(1001);
printId("A-2024");
console.log("scores总和:", scores.reduce((a, b) => a + b, 0));
（运行结果）
