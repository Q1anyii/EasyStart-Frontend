TypeScript 速成

TS = JS + 类型标注。你有 Java 基础，核心概念就是"把 Java 的类型系统搬过来"。左边是 TS 代码，右边是运行结果。

▼ TypeScript 代码（改这里，下面实时运行）
        interface Todo{ // interface 和 class都是用于声明一个对象并声明属性
            id: number,
            text: string,
            done: boolean
        }
        const todos: Todo[] = [
             { id: 1, text: "学TS", done: false }
        ];
        todos.map(t => {
            console.log(t.id);
            console.log(t.text);
            console.log(t.done);
        })
        function calculate(a: number, b: number, op: string): number { //如果传入类型不匹配会报错
            if (op === "+") return a + b;
            else if (op === "-") return a - b;
        }
        console.log(calculate(1, 2, "+"));
        function formatId(id: number | string): number | string {
            // 联合类型 vs 方法重载：重载是多个同名函数不同参数列表；联合类型是一个位置可以接受多种类型，函数体内部要自己判断分支
            if (!isNaN(id)) {
                id = "#" + id;
            } else {
                id = id.toUpperCase();
            }
            return id;
        }
        console.log(formatId(12))
        interface User {
            name: string;//必须在对象创建时显式传入
            age: number;
            phone?: string;  // ? = 可选字段,如果没有传入不影响对象正常创建
        }
        const u1: User = { name: "QQ", age: 20, phone: "1232131"};
        const u2: User = { name: "AA", age: 19};
        function greet(user: User): string {
            return `你好，${user.name}，今年${user.age}岁，号码${user.phone}`;
        };
        console.log(greet(u1));
        console.log(greet(u2));
（运行结果）

改动任务

  1. 定义一个 Todo 接口：{ id: number, text: string, done: boolean }，然后创建一个 Todo 数组并 map 输出（注释写：interface 和 Java 的 class 有什么相似处）
  2. 函数加类型：写一个 calculate(a: number, b: number, op: string): number，op 是 "+"/"-"，返回计算结果（注释写：TS 在编译时就会检查你传的类型对不对）
  3. 联合类型实战：写一个 formatId(id: number | string)，number 时前面加 "#"，string 时转大写（注释写：联合类型和 Java 的方法重载有什么区别）
  4. 可选字段：给 User 接口加一个可选的 phone?: string，创建两个 User（一个有 phone 一个没有），都能正常调用 greet（注释写：? 可选字段和必填字段的区别）
